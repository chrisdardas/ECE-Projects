## Overview

The projects focus on fundamental concepts in estimation and detection theory, including:

- Maximum Likelihood Estimation (MLE)
- Minimum Mean Square Error (MMSE) estimation
- Bayesian estimation techniques
- Detection theory and hypothesis testing
- Cramer-Rao Lower Bound (CRLB)
- Signal detection in noise

---

## 📊 Project Topics

| Topic | Description |
|-------|-------------|
| Parameter Estimation | Estimating unknown parameters from noisy observations |
| Distribution Estimation | Fitting probability distributions to data |
| Detection Theory | Binary and M-ary hypothesis testing |
| Optimal Detectors | Neyman-Pearson and Bayesian detectors |

## 💻 MATLAB Implementation

The `Matlab Code` folder contains implementations of various estimation and detection algorithms:

| File | Description |
|------|-------------|
| `thema1.m` | Parameter estimation problem |
| `thema2.m` | Distribution estimation and fitting |
| `thema3.m` | Detection theory implementation |

**Key Features:**
- Monte Carlo simulations for performance evaluation
- ROC curve analysis
- Comparison of different estimators
- Visualization of estimation error

## 🚀 How to Run

1. Open MATLAB
2. Navigate to the `Matlab Code` folder:
   ```matlab
   cd 'Estimation & Detection Theory/Matlab Code'
   ```
3. Run individual theme files:
   ```matlab
   thema1
   thema2
   thema3
   ```
