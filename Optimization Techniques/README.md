## 🧬 Final Project: Genetic Algorithms

Implementation of genetic algorithms for global optimization.

📄 Project Description: [`Project.pdf`](./Final-Project/Project.pdf)

### MATLAB Implementation

Located in `Final-Project/Matlab Code/`:

**Key Features:**
- Population-based search
- Selection operators (tournament, roulette wheel)
- Crossover and mutation operators
- Fitness function evaluation
- Convergence monitoring

**Algorithm Components:**

| Component | Description |
|-----------|-------------|
| **Initialization** | Random population generation |
| **Selection** | Survival of the fittest |
| **Crossover** | Genetic recombination |
| **Mutation** | Random genetic variation |
| **Elitism** | Preserving best solutions |

**Applications:**
- Function optimization
- Combinatorial problems
- Engineering design optimization
