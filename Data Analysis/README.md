## Overview

The projects involve analyzing datasets to extract meaningful insights, covering:

- Data preprocessing and cleaning
- Exploratory data analysis
- Statistical modeling and hypothesis testing
- Regression analysis
- Visualization techniques

---

## 📈 Chapter 2: Descriptive Statistics

Exercises covering fundamental statistical measures and data visualization:

- Mean, median, variance, and standard deviation
- Histograms and box plots
- Data distribution analysis

**Files:** `exercise2_1.m` through `exercise2_6.m`

---

## 🎲 Chapter 3: Probability Distributions

Exercises exploring probability distributions using real-world datasets:

- Normal and exponential distributions
- Parameter estimation
- Goodness-of-fit tests

**Files:** `exercise3_1.m` through `exercise3_12.m`, plus helper functions
**Dataset:** `eruption.dat` (Old Faithful geyser data)

---

## 📐 Chapter 4: Hypothesis Testing

Statistical hypothesis testing exercises:

- t-tests and chi-square tests
- Confidence intervals
- P-value interpretation

**Files:** `exercise4_1.m` through `exercise4_3.m`

---

## 📉 Chapter 5: Regression Analysis

Linear and multiple regression analysis with various datasets:

- Simple linear regression
- Multiple regression models
- Residual analysis

**Files:** `exercise5_1.m` through `exercise5_9.m`, plus helper functions
**Datasets:** `hospital.txt`, `lightair.dat`, `physical.txt`, `rainThes59_97.dat`, `tempThes59_97.dat`

---

## 🔬 Chapter 6: Advanced Topics

Advanced statistical methods:

- ANOVA
- Non-parametric tests
- Time series analysis

**Files:** `exercise6_1.m` through `exercise6_6.m`
**Dataset:** `yeast.dat`

---

## 🚀 How to Run

1. Open MATLAB
2. Navigate to the desired chapter folder
3. Run individual exercise files (e.g., `exercise2_1.m`)
4. For the final project, run files in order starting with `Group47Exe1Prog1.m`
