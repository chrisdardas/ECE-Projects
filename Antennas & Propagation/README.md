## Overview

The projects explore various aspects of antenna theory and electromagnetic wave propagation, including:

- Radiation patterns of different antenna types
- Antenna array configurations and beamforming
- Propagation models and path loss calculations
- Simulation of electromagnetic fields using 4nec2
